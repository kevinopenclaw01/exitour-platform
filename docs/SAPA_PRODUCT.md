# 사파 단독 패키지 운영 기준

## 공개 경로와 데이터

- 공식 상세: `/vietnam/sapa/private-package/3n5d-sapa-hanoi`
- 공개 콘텐츠: `lib/mock/sapaPackage.ts`
- 일정 렌더링: `components/sapa/SapaItinerary.tsx`
- 연결: 홈페이지 상품 영역, 상품 목록, 베트남 국가, 사파·하노이 도시 페이지
- 기존 quote prefill helper 재사용. admin, 견적 저장 API, Supabase 유틸과 기존 migrations는 수정하지 않는다.

## 요금

성인 4인 출발 기준 성인 1인 기본요금 690,000원, 4인 합계 2,760,000원이다.
항공권과 호텔은 불포함이며 조식은 별도 호텔 예약 조건에 따른다.
아동·다른 인원·여행일·연장·변경 비용은 상담 후 확정한다. 자동 환율 적용이나 자동 가격 변경은 없다.

사용자 소유 네이버 상품 `https://smartstore.naver.com/kevintour/products/13027526993`의
`성인4인 일때 1인요금` 옵션으로 가격 단위를 대조했다. 할인율·리뷰·평점은 이전하지 않았다.

## 일정 대조와 확정 전 확인

- 원본: 사용자 제공 하노이 사파 3박5일 일정 PDF 및 경비내역 XLSX, 네이버 상세 안내
- Day 1~3 사파 호텔 3박, Day 4 관광 후 공항 이동, 심야 귀국 기내박, Day 5 한국 도착
- 원본 식사 포함 문구와 실제 식사 행의 횟수가 달라 공개 화면에는 총 횟수를 확정하지 않는다.
- 함종공원과 므엉밸리 관련 원가표 메모는 대체 코스 여부를 확인해야 한다. 임의로 기본 코스를 변경하지 않는다.
- 항공편, 가이드 미팅 위치, 식사 횟수·메뉴, 표기 입장권, 최종 취소 조건은 예약 전에 재확인한다.

## DB 저장 상태

2026-10-16 웹사이트 전용 `exitour-platform` 복구를 요청했으나 조직 서비스 제한으로 거절됐다.
유료 업그레이드·다른 DB 사용·RLS 변경은 수행하지 않았다. 현재 페이지는 정적 기본요금으로 표시한다.
승인된 DB 대상은 `mdneuvnqwcorvinvtawp`이다. 제한 해제·복구 후 실제 스키마를 먼저 확인한다.
저장 대기 파일은 대화 작업 폴더의 `sapa-rate-upload.pending.sql`이며 실행되지 않았다.
원가·마진 분석 자료는 사이트와 Git 업로드 대상 밖에 보관한다.

복구 후에는 상품을 slug로 연결하고 공개 요금에는 판매가·인원·적용 조건만 저장한다.
원가·환율·마진은 공개 `product_rates`에 넣지 않는다. 해당 테이블은 활성 행 공개 조회 정책이 있어
민감 컬럼을 함께 넣으면 노출될 수 있다. 별도 비공개 저장 구조와 서버 권한을 확인한 뒤 적재한다.
실제 저장 후 조회·중복·익명 접근 범위를 검증하기 전에는 DB 저장 완료로 보고하지 않는다.
